# urri34 Home Assistant add-ons

[![Add repository to my Home Assistant][repo-badge]][repo-link]

Community add-ons (apps) for Home Assistant OS / Supervised.

## Installation

1. Click the button above, or in Home Assistant go to **Settings → Add-ons → Add-on Store → ⋮ → Repositories**
   and add `https://github.com/urri34/ha-addons`.
2. Find the add-on in the store and install it.

## Add-ons

### [Claude Code Remote (unofficial)](claudeforha/)

![amd64][amd64-badge] ![aarch64][aarch64-badge]

Talk to your Home Assistant from [claude.ai/code](https://claude.ai/code) or the Claude mobile app. Runs
Claude Code in Remote Control mode inside Home Assistant, with access to the HA API, the `ha` CLI and the
configuration files, plus a web UI (English / Catalan) to log in and configure everything.
Needs a claude.ai Pro, Max, Team or Enterprise account.
